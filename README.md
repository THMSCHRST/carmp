Multiplayer Car Prototype

to run the server (required): start run_server.py |
to run the client: start frame.py

how to install:

Windows:

Step 1:
download the code from this github repository

Step 2:
unzip the downloaded file

Step 3:
open the folder in cmd (cd C:path/to/the/folder)

after that run "pip install -r requirements.txt"

Last Step:
open frame.py (python required)
